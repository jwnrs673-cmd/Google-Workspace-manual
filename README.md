# Google Workspace 社内マニュアル

社内で Google Workspace を活用するための「使い方」＋「社内ルール」をまとめたマニュアル集です。
1マニュアル＝1ファイルで、テーマごとに追加していきます。

## 構成の考え方

- **アプリ(機能)ごとにフォルダを分ける** — 探しやすく、増やしやすい
- **共通ルールは `00_共通ルール/` に集約** — アカウント/セキュリティ/命名規則など、全アプリ横断のルールは重複させない
- **各マニュアルは「機能説明 → 社内ルール」の順で統一** — [`_templates/マニュアルテンプレート.md`](_templates/マニュアルテンプレート.md) を雛形として使う

## マニュアルの追加方法

1. 対象アプリのフォルダを開く
2. [`_templates/マニュアルテンプレート.md`](_templates/マニュアルテンプレート.md) をコピーして、テーマ名でリネームする
   - 例: `01_Gmail/署名の設定.md`
3. 「機能の説明」と「社内ルール」を記入する
4. 画像は `_assets/` に置き、相対パスで参照する

## 命名ルール

- ファイル名はテーマがひと目でわかる日本語で(例: `ラベルとフィルタの使い方.md`)
- フォルダ番号(`01_` 等)で並び順を固定
- 画像は `_assets/アプリ名_テーマ_連番.png` の形式を推奨
